# Приложение сотрудника SHPURA — выпуски для Android

Здесь лежат установочные файлы (APK) приложения сотрудника интернет-магазина на SHPURA. Google Play не нужен:
приложение само проверяет новую версию и предлагает обновиться.

## Как это работает

- Каждый выпуск — раздел **Releases** с файлами `SHPURA-mobile-<версия>.apk` и `latest.json`.
- `latest.json` — номер последней версии, адрес APK, контрольная сумма SHA-256 и что нового.
- Сайт магазина читает `https://github.com/1s83gnsh/shpura-mobile-releases/releases/latest/download/latest.json`
  и передаёт приложению. Приложение скачивает APK, сверяет сумму и ставит через системный установщик Android.
- Все выпуски подписаны одним постоянным ключом — поэтому обновление встаёт поверх прежней версии.

## Первая установка

1. Скачайте APK последнего выпуска на телефон и откройте его.
2. Разрешите установку из этого источника, когда Android спросит.
3. Откройте приложение и войдите по QR-коду со страницы «Мобильное приложение» в админке своего магазина.

Без QR-кода магазина приложение ничего не показывает: данных и ключей в файле выпуска нет.
